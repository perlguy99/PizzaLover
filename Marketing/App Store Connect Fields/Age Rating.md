# Age Rating

App Store Connect's age rating is a questionnaire, not a single paste field - answer every category **"None"/"No"** for Pizza Lover:

- Violence, horror, mature/suggestive themes, profanity: None
- Alcohol, tobacco, drugs: None
- Gambling (simulated or real-money): None
- Unrestricted web access: No (the app has no in-app browser)
- User-generated content shared with or visible to other users: No - photos/notes a user adds are private to their own iCloud account, never shared with or visible to anyone else, no social/feed feature exists
- Contests: None
- Medical/treatment information: None

Expected result: **4+**. Nothing in Pizza Lover's actual feature set should trigger a higher rating - no network-connected content outside MapKit place search and the user's own iCloud data.
